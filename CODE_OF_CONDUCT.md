# Code of conduct

claudia-theme is a friendly, creative project. Everyone who takes part — in issues, pull
requests, discussions or anywhere else in the project — is asked to:

- **Be kind and respectful.** Welcome newcomers; assume good intentions.
- **Be constructive.** Critique work, not people; explain the why behind feedback.
- **Keep it appropriate.** No harassment, insults, discrimination, or sexual or violent
  content, including in artwork contributed to the project.
- **Respect others' work.** Only contribute code and art you have the right to share, and
  credit others' work.

The maintainer may edit or remove comments, issues, pull requests or artwork that break these
guidelines, and may block people who repeatedly do so.

To report a problem privately, contact the maintainer through their GitHub profile.
