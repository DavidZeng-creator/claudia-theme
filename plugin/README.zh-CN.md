# claudia-theme 使用说明

为 Claude 桌面（及移动）应用中的 Claude Code 会话设计的主题，以橙发图书管理员角色与
华丽的 "Claude" 标志为基础。

- **开场（约 6 秒，每次新会话）：** 开场开始时会测量聊天区域，书本与标志完整地显示在
  聊天区域中央，避开会话列表和右侧边栏，并按比例缩放；一本书展开，标志的字母逐个升起，
  花朵绽放，丝带舒展，流苏摆动，花瓣迸散；随后她在柔和的光芒中升起现身，花瓣环绕飞舞。
- **背景：** 角色站在右侧，在任何窗口比例下都以相同的高度比例从头到脚完整显示，伴有
  花瓣、金色光点和沿底部的裙摆刺绣花边。浅色模式为奶油色羊皮纸，深色模式为黑色天鹅绒与灯光。
- **配色：** 整个应用采用裙装的配色（橙、奶油、近黑、金、书本红）。

## 安装

在终端中的 Claude Code 会话提示符处输入：

```
/plugin install claudia-theme --marketplace DavidZeng-creator/claudia-theme
```

输入 `y` 添加插件市场，然后选择一个范围（列表第一项"用户范围"会让它在所有会话中生效）。
也可以在命令行中运行：

```
claude plugin install claudia-theme --marketplace DavidZeng-creator/claudia-theme
```

在桌面应用中（`/plugin` 无法在此运行）：点击提示框旁的 **+**，然后 **Plugins**，
**Add marketplace** 输入 `DavidZeng-creator/claudia-theme`，再点击 **Add plugin**。

主题显示在 Claude 桌面应用的 Code 标签页（以及移动应用）中；终端会话只提供 `/claudia` 命令。

## 让她与你的窗口对齐（点击一次）

背景覆盖整个窗口，但应用只告诉插件聊天区域的宽度，所以插件需要测量一次左侧的会话列表：

1. 关闭右侧边栏。
2. 打开 ✿ 菜单并选择 **Calibrate**（或输入 `/claudia calibrate`）。
3. 在会话列表右侧紧挨着边缘的背景上点击一下。

插件根据点击的位置算出会话列表的宽度并记住它；此后开场的标志会居中于聊天区域，她也会
正好站在右侧边栏旁边。调整或折叠会话列表、或更改应用文字大小后，请重新校准。
提示框上方栏中的 **Cancel** 可停止等待点击；`/claudia calibrate reset` 会清除测量结果。
应用以窗口宽度的 1/64 为步长报告点击位置，所以结果误差约为一列。

## 设置

- **Session list width（会话列表宽度）**（`session_list_columns`，默认 25）：仅在未校准时使用。
  会话列表的宽度，以应用的字符列为单位；折叠时为 0。安装时会询问，之后可在插件设置
  （`/config`）中修改。

## 使用

- **小花** ✿ 是提示框上方唯一的元素：位于提示框右上角的一朵橙色小花。点击后，选项会在
  它旁边排成一行，均为纯文字、没有按钮，鼠标悬停的选项会高亮：White dress（白色连衣裙）、
  Maid outfit（女仆装，✓ 标记当前服装）、Clarity（清晰度，0-100% 滑条；移动应用中为 − 和 +）、
  Replay opening（重播开场）、Calibrate（校准）和 Hide background（隐藏背景）。窗口太窄
  放不下一行时会自动换行。选择一项后菜单关闭；调整清晰度滑条时菜单保持打开，再次点击小花
  即可关闭。所有选择都会被记住。
- **Hide background（隐藏背景）** 关闭插件的外观：应用恢复自己的配色与背景，只保留提示框
  上方的小花。这个选择会被记住，下一次会话同样不会显示开场。此时小花的菜单里只有
  **Show background（显示背景）**，选择它会以入场动画恢复整个外观：羊皮纸淡入，她在光芒
  与花瓣中升起。`/claudia off`、`/claudia on` 以及右键菜单中的选项效果相同。
- **右键菜单：** 在对话中右键单击会添加几项：切换服装、清晰度增减 10%、打开菜单、隐藏背景
  （背景关闭时只有"显示背景"）。
- **右侧边栏与窗口大小：** 窗口宽度一有变化（哪怕很小），她会立即消失（提示框上方栏中一条
  看不见的感应条会马上察觉）。之后的连续变化不会触发任何动画；等一切静止后，她会以入场动画
  （光芒绽放、花瓣旋转、身影升起）回到原位，羊皮纸保持不变，然后切换为清晰的图像。右侧边栏
  打开时，她会站在边栏旁边。清晰度不变。拖动窗口改变大小不会移动她（边栏通过一次快速跳变
  来识别）。
- `/claudia` 打开菜单；`/claudia intro`、`/claudia dress`、`/claudia maid`、
  `/claudia 0`–`/claudia 100`、`/claudia calibrate`、`/claudia calibrate reset`、`/claudia off`
  和 `/claudia on` 也可使用。点击空白背景同样可以切换服装。
- 切换服装时会播放一道闪光与旋转的花瓣，她以另一套服装现身（约 2 秒）。

## 已知限制

- 桌面应用只为单独交付的一张图画播放背景动画，而且只在第一次见到这段内容时播放；叠放在
  容器中的图画是静止的。所以开场、入场、每次换装以及窗口变化后的回归，都是带有新标记的
  单张图画。一张图画最多 131,072 个字符，因此动画中的她是简化版；动画结束后由清晰的静态
  分层图像接替。
- 桌面应用会在背景超过固定总大小时（约 22 万至 32.5 万字符之间，与屏幕无关）静默拒绝绘制，
  所以她的描摹轮廓被简化到不到一个像素的精度，整个背景保持在 22 万字符以内。
- 应用会在提示框上方栏中的任何内容后面绘制一条全宽的底条；插件无法去掉它，所以菜单以一行
  展开，尽量让它保持短小。
- 右侧边栏的状态会在会话之间被记住：如果新会话开始时的聊天宽度与上次边栏打开时相同，就认为
  边栏仍然打开。在没有会话运行时以相同宽度打开或关闭的边栏，会被误判，直到下一次打开或关闭。
- 窗口退出全屏时，应用会隐藏右侧边栏（会话栏），回到全屏时再显示。插件通过"窗口变小而聊天
  区域变宽"（她移到边缘）和"窗口变大而聊天区域变窄"（她回到边栏旁边）来识别这一情况。
- 调整或折叠会话列表、或更改应用文字大小后，请重新校准（见上文）。
